Extract Questions
Parse a paper into structured JSON — no formatting, no output docs
POST /api/extract — Upload any paper format; backend returns a questions.json only. Use this when you want to inspect or edit the extracted questions before building the final docs. The JSON can then be fed into Solutions Doc or Answer Key workflows directly. Accepts: .docx, .pdf, .png, .jpg, .jpeg, .webp up to 50 MB.

Solutions Doc
Generate the teacher-only solution document from a questions JSON
POST /api/solutions — Takes a questions.json (from Extract or manually written) and builds the teacher solution doc (.docx) with answers, reasoning, source citations, and any flagged questions. Toggle AI Explanations to have the backend call the LLM to generate full worked solutions for each question — costs more time and API tokens.
