Backup & data

All data lives in this browser only (localStorage), so it is never committed to the public repo. Export a JSON backup regularly. To move machines or recover, Import the file.

How to use

Daily rhythm (matches linkedin-playbook §14.1):

1. Comment on 5–10 prospects' posts. For each, paste their URL on the Pipeline tab and hit Add (logs the comment + bumps the LinkedIn-comments counter).
2. The app waits 2 days, then shows them under Needs attention today with "Send connection request." Tick it once sent.
3. When LinkedIn says they accepted, hit Accepted → it then prompts the first message → then Loom on silence, all on the §14 cadence.

Counters: tap + after every post, reply, comment, dial, or call. Advancing a prospect's stage auto-ticks the matching counter, so don't double-count those. Set a daily target by clicking the small target icon.
