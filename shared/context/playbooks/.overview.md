# shared/context/playbooks — Channel Playbooks

> **⚠️ ALL FILES SUPERSEDED (pre-2026-06-06, beauty DTC).** Niche pivoted to education / coaching on 2026-06-06. Every file in this folder has a SUPERSEDED banner. ICP, post angles, offer numbers, and DivineSide-specific copy are beauty-era and not yet migrated. Structural mechanics (frameworks, principles, writing rules) remain useful as scaffolding. Do NOT generate coaching-niche content from these files without migrating them first. Migration is downstream of the entry-workflow deep-research phase.

Channel-specific tactical playbooks for content and outreach. Each file extends [`../identity/voice.md`](../identity/voice.md) + the relevant persona ([`../identity/pang.md`](../identity/pang.md) or [`../identity/mayank.md`](../identity/mayank.md)) with platform-specific structure.

## Files

| File | What it contains |
|------|------------------|
| `linkedin-playbook.md` | Pang's LinkedIn tactical playbook — hooks / CTAs / closings swipe sections, 3 post frameworks (PAS, SLA, Case Study), writing flow, profile copy, growth strategy, differentiation requirement, pre-publish checklist. |
| `x-playbook.md` | Pang's X (Twitter) tactical playbook — flywheel (content→profile→email→offer→proof), breakpoint diagnosis, X writing guidelines, naughty word list. v0 strategic frame; swipe files come later. |
| `reviews-offer-outreach.md` | **Copy-paste outreach templates for the reviews/referrals offer (2026-06-10).** Warm-reply LinkedIn first message (+ message two), the Loom-delivery email (short, no apology), the ~90s Loom script (lead-with-value, free-trial de-risk, soft referral tease), and the Notion contrast visual (template-bot vs AI conversation). No fabricated case study, no incentivized reviews. Companion to `cold-call-script.md`. |
| `cold-call-script.md` | **Honest cold-call script (2026-06-10) for the reviews/referrals offer, US test prep / tutoring.** Opener (pattern interrupt) → hook (real review-gap observation + two-week free trial, NO fabricated case study) → book-on-call manually → pre-frame → show-up texts → full objection handling → voicemail. The free trial is the de-risk that replaces a case study. Pairs with `linkedin-playbook.md` §14 and `offer.md`. |
| `upwork-loom-script.md` | The standardized Upwork Loom video script — ~5:30 length, eight sections (open, JD-specific demo, offer+guarantee, contrast, metaphor, RM AIOS three-layer demo, tie-back, close). Variables to fill per recording. |
| `outbound-playbook.md` | **Cross-channel cold-outreach SOP.** 7 psychological principles, 4-step copy framework (personalization / who-am-I / offer / CTA), the offer formula `(ROI × Trust) / Friction` with 9 worked examples, channel-specific optimization (email / LinkedIn / X / IG / SMS surfaces), subject lines, follow-ups, iteration discipline, AI usage rules, grey-hat awareness, 13-point pre-send checklist, forbidden phrases. Every cold email/DM/SMS loads this. |
| `swipe-file.md` | Cross-channel raw content examples — LinkedIn / X / YouTube / cross-channel patterns. Holds the *moves* (real posts/threads with notes on what specifically works). Templates stay in per-channel playbooks. |
| `Outreach-copywriting-transcript` | **Source material — do not load for normal work.** Raw 4.5-hour transcript distilled into `outbound-playbook.md`. Reference only. |

**Pattern: persona file always first**, then the channel playbook, then optional swipe examples. Persona owns *who is writing*; playbook owns *how the channel demands the writing be structured*.
