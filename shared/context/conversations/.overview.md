# shared/context/conversations — External Conversation Log

> **Permanent, append-only log of every external conversation.** Sales calls, discovery calls, DM exchanges, partner/vendor conversations, Looms. The transcript stays in Supabase (Fathom) or in the original channel (DM, email); this folder holds the **distilled signal** in a consistent format so future-you, the cofounders, and downstream agents can scan a year of conversations in minutes.

Not sprint-specific. Every external call from now on lands here.

> **Niche pivot 2026-06-06:** notes are now about **education / coaching** owners. The template below was written for beauty DTC, so its "Stack snapshot" and "8 pillars" sections are beauty-era. For coaching notes, map those to the **four institute functions** (Product / Marketing / Customer Service / Sales) instead, as done in [`2026-06-05-beachhead-coaching-owner-call.md`](2026-06-05-beachhead-coaching-owner-call.md). The template itself is on the downstream rewrite list. Old beauty-DTC notes stay as-is (append-only).

## What goes here

- 1 markdown file per conversation
- Filename: `YYYY-MM-DD-shortname-channel.md` (e.g. `2026-05-27-rahmatul-azmi-intrepit-call.md`, `2026-05-27-anonymous-smm-shopee-dm.md`)
- Filled in **after** the conversation, not during. Take rough notes live, distill into the template later that day.

## What does NOT go here

- Full transcripts of recorded calls. They live in Supabase (`meetings` table, populated by the Fathom integration). Just link to them.
- DM conversations where there's nothing to learn. Skip the log entirely.
- Internal cofounder syncs. Those have their own home (`.claude/` alignment docs, or Fathom-only).
- Speculation or post-hoc synthesis. Notes are facts and verbatim quotes; pattern extraction across notes happens in dedicated synthesis docs written when a decision needs to be made.

## File template

```markdown

- Referrals:

(Mark "not discussed" for any pillar that didn't come up. Better than guessing.)

## Surprise / non-obvious quote
The one thing they said that you didn't expect. Verbatim if possible.

## Wand wish
What they said when asked "if you could wave a wand and have one thing run itself."

## Budget signal
What they pay for and resent. What they said they'd happily pay for. (Skip if they have no purchase authority.)

## Language signal
2-3 phrases they used to describe their pain, verbatim. This becomes our marketing copy when patterns emerge across notes.

```

## Loading discipline

| Task | Load from here when |
|---|---|
| Writing or revising `identity/audience.md` | Yes — mine recurring language across notes |
| Writing or revising `identity/voice.md` | Yes — mine the words founders actually use |
| Writing or revising `sales-and-delivery/offer.md` | Yes — pricing signals, workflow demand evidence |
| Writing or revising `identity/strategy.md` | Yes — niche signals, what's already-solved vs broken |
| Generating cold emails / DMs / proposals | No — load identity + offer instead |
| Running a live sales call | No — load `sales-and-delivery/sales-discovery-jp-framework.md` instead |
| Lock meetings (offer, niche, pricing decisions) | Yes — read all notes since last lock |

## Rules

- **Append-only.** Don't rewrite old notes. If something turns out to be wrong, write a new note dated when you learned the correction.
- **Don't duplicate transcripts.** If the call was Fathom-recorded, link via `fathom-meeting-id` + `fathom-share-url`. Only paste full text for DMs / emails that aren't recorded anywhere else.
- **Niche fit is honest, not aspirational.** Mark NO if they're out of the locked niche even if they're an interesting conversation.
- **Verbatim quotes win.** Paraphrased pain doesn't make it into marketing copy. Verbatim does.
- **L0 discipline:** when adding the first note about a fundamentally new conversation type (vendor calls, partner calls), update this `.overview.md` so future-you knows what fits.
