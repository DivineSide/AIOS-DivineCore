# scripts/

Repo-maintenance helpers. Small, single-purpose, run from the repo root.

## Files

- **daily-push.ps1** — Stages all tracked/untracked changes (`git add -A`), commits them as
  `chore: daily context sync <date>`, and pushes to **upstream/main** (the DivineSide org repo,
  which is the source of truth). Exits quietly when there's nothing to push.

  **Why it's safe on a PUBLIC repo:** lead CSVs and local Claude state are gitignored, so they
  never stage. As a second line of defence the script ABORTS (and unstages) if any file matching
  `*.csv`, `*.env`, `*secret*`, `token.json`, `credentials.json`, or `settings.local.json` ends
  up staged. That way a future un-ignored data file can't leak.

  It is **not** a substitute for real commits — use proper, message-rich commits for actual code
  work. This is only for keeping the docs/context folders synced day to day.

## Scheduling it daily (Windows Task Scheduler)

Run once in an elevated PowerShell to register a daily 18:00 task:

```powershell
$action  = New-ScheduledTaskAction -Execute "pwsh.exe" `
  -Argument "-NoProfile -File `"$PWD\scripts\daily-push.ps1`""
$trigger = New-ScheduledTaskTrigger -Daily -At 6pm
Register-ScheduledTask -TaskName "DivineCore daily push" -Action $action -Trigger $trigger
```

(Use `powershell.exe` instead of `pwsh.exe` if PowerShell 7 isn't installed.)

## What does NOT go here

- Module/runtime code (lives in the module folders + `divinecore-v2/`).
- Anything that needs to run inside Docker on the VPS.
